EVENT BOOTH GAMES · PRACTICAL GUIDES

Adapt an existing game or build a new one: which suits your event?

A booth game does not always have to start from scratch. If rules that already exist fit your goal, we can redesign every visual and all the content to make it yours. But if your brief calls for a different kind of play, a new game is the answer. This article helps you decide faster.

JPM Media Space·Published 16 November 2026·3 min read

Change the look, or change the rules

The first question is whether you want to change how the game looks or how it plays. If it is the look (logo, colours, products, questions), we can adapt a game that already exists. If it is how it plays (new rules, a new sensor, several screens playing at once), it should be built new.

PointAdapt an existing gameBuild a new game
Best forWhen the existing rules already fit your goalWhen you want an experience no one else has
Time neededShorter, good for rush jobsNeeds more time to design and test
Cost controlEasier to keep within budgetDepends on the rules and the technology
How much is your brandAll the visuals and content are yoursThe visuals, the content, and the rules

To see what usually goes into the total, read what a booth game budget includes.

Try a demo first, then tell us what to change

The games in our Playground, such as Catch, Tap the Right Item, Memory Match, Lucky Wheel, and Quick Quiz, are a good starting point. Play them and note what you would change, such as swapping the items for your products, adding a sign-up step, or playing on an LED screen instead of a touchscreen. That list lets us tell you quickly whether to adapt or build new.

Think about your next event too

If you run booths at several events a year, a game designed so its content is easy to change pays off over time. The system we hand over can be updated, moved, or built on. Tell us how you plan to use it when we first talk, and we will design it for that. See how we build booth games.

FAQ

Is a ready-made game always cheaper?

It is usually easier to keep within budget, but if the rules need a lot of changes, it may cost about the same as building new. See the starting prices on our packages page.

Can we reuse the game at the next event?

Yes. We design it so it can be updated, moved, or built on.
